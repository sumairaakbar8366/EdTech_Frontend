Download Android app (APK) After it downloads, open the file and tap Install. If Android asks, allow "Install unknown apps" for your browser.

On iPhone, install it from Safari:

  1. Open skooledtech.com in Safari.
  2. Tap the Share button.
  3. Choose Add to Home Screen, then Add.
